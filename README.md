# 重庆八日 · 行程

8月29日 – 9月6日，4 大 4 小。一个单文件的行程页，打开就是行程。

## 这一版做了什么

- **双版本切换**：封面下方「我的排法 / 导游原版」一键切换。导游原版来自
  旅行社《8.29-9.5 号马克确认件》，当天情况不理想时可随时看回导游的排期。
  两个版本各自有完整的时间轴、图标、导航、小红书入口和「现在在这一站」

- **一进去就是行程**：顶部压到最薄，日期条下面直接是当天的时间轴。不再需要往下滚过总览、改动说明才看到行程
- **一次只看一天**：8 个日期做成吸顶的横向切换条，点一下换一天。行程当天打开会自动停在今天
- **每条安排都有图标**：按内容自动分成四类配色 —— 看（青绿）、吃（琥珀）、动（蓝）、歇（紫），扫一眼就知道这个时段在干嘛
- **其他资料收起来**：总览表、动线核查、给导游的确认清单、费用、景点索引全部放进底部一个折叠区，默认关着，需要时点开，一条都没丢
- **小红书关键词修好了**：原本渣滓洞搜的是「重庆渣滓洞 预约」，会搜出一堆订票帖；改成「攻略」，搜到的才是景点本身的内容

## 保留的

- 26 个景点的讲解弹窗（点带虚线下划线的地名），含带孩子提示、门票时间
- 小红书关键词 + 高德地图定位两个按钮
- 原本的青绿配色、内嵌 CQ Serif 衬线字体、明暗双主题
- 不加载任何境外资源，中国大陆可正常打开，离线可用，可「添加到主屏幕」

## 文件

只有 `index.html` 一个文件，浏览器直接打开就能用，也可以丢到任何静态托管。

改行程内容：搜 `<article class="day"` 找到对应那天；改景点讲解：搜 `const POI` 找到对应景点。
