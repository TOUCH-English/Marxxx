# 我的行程 · Marxxx

一个只做「看行程」这一件事的页面 —— 打开就是行程，没有其他杂项。

## 功能

- **一进去就是行程**：首页直接显示行程时间轴，按天切换（DAY 1 / DAY 2 / …），自动带出日期和星期
- **漂亮的分类图标**：航班 ✈ / 住宿 / 美食 / 景点 / 交通 / 购物 / 其他，每种类型有自己的颜色和图标
- **小红书攻略按钮**：每个行程卡片上一键搜攻略 —— 只取干净的景点名（自动去掉「预约」「门票」这类干扰词），复制关键词并打开小红书搜索，搜到的就是景点本身的攻略
- **花费小账本**：每项可记花费（RM），自动汇总当天和全程总额
- 纯浏览模式，页面上没有任何增删改按钮

## 修改行程内容

行程写在 `index.html` 里的 `TRIP` 常量（`<script>` 开头处），改那里就能更新页面：

```js
const TRIP = {
  title: "我的旅程",
  startDate: "2026-08-21",
  days: [
    { activities: [
      { time: "08:30", cat: "flight", title: "出发 ✈ 前往目的地", loc: "机场 T1", note: "提早 2 小时到机场" },
      { time: "13:00", cat: "food",   title: "抵达后吃第一餐", cost: 50 }
    ]},
    // 一个 { activities: [...] } 就是一天
  ]
};
```

- `cat` 可选：`flight` 航班 / `hotel` 住宿 / `food` 美食 / `sight` 景点 / `transport` 交通 / `shopping` 购物 / `other` 其他
- `loc`（地点）、`note`（备注）、`cost`（花费 RM）可以不填
- 天数由 `days` 数组决定，日期从 `startDate` 起自动往后排

## 使用

纯静态单文件，无需构建：

- 本地：直接用浏览器打开 `index.html`
- 部署：丢到任何静态托管（Vercel / Netlify / GitHub Pages）即可
