# 经验积累与改进（docs/learning-loop.md）

这里的「学习」是：积累可检索的经验 → 提出有明确假设的政策改进 → 在隔离模拟中验证 → 由您确认一次才切换版本。
不是训练模型权重，也不承诺交易越多越赚钱。

## 调度（马来西亚时间；演示/回放按回放时钟）

| 任务 | 时间 | 去重键 | 数据不足时 |
| --- | --- | --- | --- |
| 中文日报 | 每天第一次运行时补齐最近 7 天未生成的日报 | `DAILY:<账本>:<日期>` | 写明「没有决策或订单」及原因统计，不伪造结论 |
| 经验收集 | 每天 | `trade:/rej:/exec:/notrade:` | — |
| 周度改进分析 | 新的 ISO 周开始后分析上一周 | `WEEKLY:<账本>:<年-W周>` | 「证据不足，保持当前版本」 |

去重键有数据库唯一约束，重启不会重复执行，也不会重复提出相同候选。跨市场：美股同一交易日在马来西亚时间次日凌晨收市，日报注明未完成交易。

## 经验记录

已平仓交易（盈利、亏损、扣费后亏损、被止损的信号错误、执行故障）、被风控拒绝、无效 AI 输出、执行失败、每日不交易统计都会记录，
包含数据时点、政策版本、理由、费用、滑点、持有时间与结果。模拟（演示/历史回放）与实盘经验分别存放在 sim / live 数据库，并按数据来源标记；
未平仓浮盈不计入已实现盈利。经验 `verified=false`，**不会注入提示词或改变任何运行中的行为**。

## 候选改进

- 每个候选只改变一个参数，且只能是白名单内的决策参数（`TUNABLE_PARAMS`：入场门槛、止损 ATR 倍数、止盈倍数、最长持有期、减仓触发、退出阈值、候选数量）。
  不能扩大股票池、提高资金或风险额度、取消保护、启用融资或修改代码。
- 记录原版本、变化、假设、证据、预计收益与可能代价；候选版本以 `CANDIDATE` 状态保存，不影响运行版本。
- 首版由确定性规则提出候选（例如「多数亏损交易以止损结束 → 提高入场门槛」）；也可接入 AI 提出，同样受白名单限制。

## 评估（先冻结，再比较）

- 评价指标与门槛在候选创建时写入 `eval_plan` 并冻结：
  最少 8 笔已平仓交易、窗口 20–90 天、净收益至少改善 0.5 个百分点、最大回撤恶化不超过 0.5 个百分点、费用占比不显著上升。
- 只使用「候选生成之后」并且「当前业务时间之前已收盘」的数据，基准（当前运行版）与候选在同一窗口、同一费用与撮合假设下回放比较。
- 结果：满足门槛 → `READY_FOR_REVIEW`；样本不足或不同市场结果冲突 → 延长模拟，到最长窗口仍不足 → `INSUFFICIENT_EVIDENCE`；未达标 → `REJECTED`。
  所有候选（包括失败的）都保留，页面显示试过多少、失败多少。
- 限制：首版的自动评估针对「固定测试响应」政策参数；使用真实模型时，候选需要以影子模式前向模拟评估（未自动实现，标示为未验证）。
  历史 AI 回放可能受模型已知历史事件影响，不能作为无泄漏的收益证明。

## 上线与回退

- 状态：PROPOSED → SIMULATING → INSUFFICIENT_EVIDENCE / REJECTED / READY_FOR_REVIEW → APPROVED → ACTIVE → ROLLED_BACK。
  通过测试只表示「可以审核」，不代表已获准控制实盘。
- 上线：在「复盘与改进」页面查看中文差异与证据，再次输入密码确认一次。只影响新决策；已有持仓保留买入时的止损/止盈/持有期限。
  现行运行授权内的自动交易继续，不需要重新授权（此确认是策略升级，不是逐笔确认）。
- 回退：一键回到上一版本，记录审计；回退**不会**清除任何亏损锁定、不会重新下单、不会放宽保护。
  只有您预先授权且验证过的回退路径才可自动回退（首版只在异常时暂停新开仓并通知，不自动回退）。
- 所有上线、回退、暂停都有审计记录（`deployment_history` 与审计日志）。
