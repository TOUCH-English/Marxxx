# 风控政策（docs/risk-policy.md）

风控由确定性程序执行，AI 无法修改或绕过。以下数值是**模拟测试种子**；实盘必须在实盘页面单独设置并确认（不会继承模拟参数），
放宽任何参数需要再次输入密码。

## 参数（模拟种子）

| 参数 | 种子值 | 含义 |
| --- | --- | --- |
| max_position_pct | 10% | 单标的仓位上限（含已持有与待成交买单），按该币种策略净值 |
| max_total_exposure_pct | 30% | 总投入上限（持仓市值 + 待成交买单） |
| risk_per_trade_pct | 0.25% | 单笔计划风险（止损距离 × 数量 + 预估双边费用 + 滑点） |
| max_positions | 3 | 同时持有标的（待成交的新标的也占名额） |
| max_daily_new_orders | 3 | 当日新开仓订单（马来西亚日期；减仓不受限） |
| daily_loss_pct | 1% | 当日亏损暂停线（含浮亏与费用，剔除入出金） |
| max_drawdown_pct | 5% | 现金流调整后的净值高点回撤暂停线 |
| max_spread_bps | 150 | 买卖价差上限 |
| max_quote_age_seconds_realtime / _replay | 15 / 1800 | 报价最长延迟（回放按回放步长） |
| entry_order_ttl_minutes | 30 | 开仓委托有效期，到期撤销未成交部分 |
| exit_reprice_minutes | 10 | 退出委托未成交则撤单后按最新买一价重新委托 |
| no_new_entries_minutes_before_close | 15 | 收市前不开新仓 |
| min/max_stop_distance_pct | 0.5% / 20% | 止损距离合法范围 |
| max_entry_premium_bps | 30 | 买入限价最多高于卖一价 |
| exit_limit_discount_bps | 50 | 保护性卖出限价低于买一价（止损限价不保证成交） |
| default_max_hold_days | 20 | 默认最长持有天数 |
| allow_margin / allow_short / allow_fx | 禁止 | 首版产品边界，任何版本都不能开启 |

产品硬上限（任何版本都不能超过）：单标的 50%、总投入 100%、单笔风险 2%、持有 10 个、每日 20 笔、日亏损 10%、回撤 30%。

## 下单前检查（全部同时检查）

模式与命名空间、运行授权（签名/状态/有效期/模式）、买入权限、策略版本、风控版本、暂停/紧急停止、风控锁定（全局与单证券）、
健康状态（行情连接、执行通道、未知订单、对账错误）、授权范围（白名单或当日股票池快照）、证券资料、证券类型（股票/普通 ETF，排除杠杆/反向）、
币种（市场币种，不换汇）、交易单位、交易时段（含午休、半日市）、收市前禁开、隔夜设置、信号有效期、报价（源时间戳、过期、停牌、买卖价）、
价差、限价合法性与价格档位、止损存在与距离、费用资料、持有名额、当日名额、重复意图；实盘另查券商「可用且可结算现金」。

## 仓位计算

```
策略净值 E = 该币种现金 + 该币种持仓市值
可用现金 C = 现金 − 其他待成交买单预留
入场限价 L = min(卖一价 × (1 + 入场溢价), AI 给出的最高买价) 取合法档位
每股风险 r = (L − 止损) + L × 假设滑点
计划风险预算 B = min(E × 单笔风险%, 可承受亏损 − 已发生亏损)
数量 = min(
   计划风险数量：最大 q 使 r×q + 买入费用(q) + 卖出费用(q) ≤ B,
   单标的上限：(E × 单标的% − 已持仓市值 − 已预留) / L,
   总额度：(E × 总投入% − 总持仓市值 − 总预留) / L,
   可用现金：最大 q 使 L×q + 买入费用(q) ≤ C,
   AI 目标仓位（如有，且不超过单标的上限）,
   券商可结算现金（实盘）
) → 向下取整到交易单位；不足一手不下单
```

缺少止损、止损距离非法或费用资料不足时不生成买单。止损只是计划：跳空、停牌、无成交时实际亏损可能更大。

## 预留与并发

校验、预留资金/风险/名额、写入订单意图在同一个 SQLite `BEGIN IMMEDIATE` 事务中完成，并发建议串行化。
成交时预留按成交金额与费用递减；终态时只释放未成交部分；状态未知时保留预留直到核对。

## 锁定语义

| 锁定 | 触发 | 解除 |
| --- | --- | --- |
| DAILY_LOSS | 当日（马来西亚 00:00 起）亏损 ≥ 日初净值 × 1% | 下一个马来西亚日界之后，且健康检查通过、无未知订单，由工作进程解除；不能手动提前解除 |
| DRAWDOWN | 现金流调整后高点回撤 ≥ 5% | 人工复核（填写说明；实盘需再次输入密码） |
| MAX_LOSS | 累计亏损 ≥ 您设定的可承受亏损 | 人工复核 |
| UNKNOWN_ORDER | 存在状态未知订单 | 全部未知订单经对账或人工核对后自动解除 |
| RECONCILE（单证券） | 券商持仓与账本不一致 | 您处理归属后人工解除；期间不自动管理该证券 |

锁定保存在数据库：重启、价格反弹、策略回退都不会解除锁定。锁定只阻止**新开仓**；保护性退出照常运行。

## 暂停与紧急操作

1. **暂停新开仓**：阻止买入新风险；止损、止盈、持有期限、AI 减仓/卖出照常。
2. **紧急停止新交易**：停止产生新开仓，逐单撤销系统挂起的入场单（逐单返回结果）；保护性订单与持仓默认保留，**不会卖出任何资产**。
3. **手动清仓**：单独的高影响操作，展示范围与估算，需勾选确认（实盘需再次输入密码）；只卖出系统管理的持仓，以买一价附近限价委托，可能部分成交。

## 保护规则

每个持仓在买入时保存止损价、止盈价（如有）和最长持有期限（随拆股同步调整），策略升级不改变已有持仓的保护。
保护由程序在行情更新时触发，不等待 AI；多个退出信号统一经过退出协调器：在途卖单剩余数量 + 新卖单 ≤ 实际持仓，保护性退出优先并撤销其他卖单。
本地模拟与客户端监控止损在电脑关机或断网时**不会触发**。
