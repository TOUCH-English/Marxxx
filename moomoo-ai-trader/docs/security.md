# 安全（docs/security.md）

## 密钥与敏感资料

- moomoo 密码与验证码只在官方 OpenD 界面输入；本系统不索要、不保存、不调用 `unlock_trade`。交易解锁由您在 OpenD 中完成。
- Anthropic API 密钥只放在本机 `.env`（已被 `.gitignore` 忽略）。设置页只显示「已配置/未配置」，不显示内容；不写入数据库、日志、前端或 AI 输入。
- 本机网页密码以 scrypt 哈希保存在 `data/secrets/web_password.json`（权限 0600）；运行授权签名密钥在 `data/secrets/authorization_hmac.key`（0600）。
- 日志写入前做脱敏（API 密钥、`password=`、`token=` 等模式）；账户 ID 在页面与诊断文件中脱敏显示（只露后 4 位）。
- `data/`（数据库、诊断结果、备份、模拟券商状态）不会提交到 Git。

## 本地网页访问控制

- 只监听 `127.0.0.1`；不开放公网，不开放 CORS（前端与 API 同源）。
- 首次使用设置本机密码；会话 Cookie 为 HttpOnly + SameSite=Strict，空闲 2 小时/绝对 12 小时过期；连续 5 次密码错误锁定 1 分钟。
- 所有改变状态的请求：必须有有效会话 + CSRF 双重提交令牌（`x-csrf-token` 与 Cookie 一致）+ Host 白名单 + Origin/Referer 校验。
  任何其他网页都无法跨站触发交易，即使服务只监听 localhost。
- 安全响应头：CSP（只允许同源脚本）、`X-Frame-Options: DENY`、`nosniff`、`Referrer-Policy`。
- 敏感操作需要 10 分钟内再次输入密码：实盘启动/授权、放宽风控、确认实盘范围、实盘费用表、手动清仓（实盘）、批准策略升级、实盘账户绑定。
- 将来如需远程访问，必须另行配置认证、TLS 与网络隔离（首版不提供）。

## 模式隔离与实盘闸门

- sim / live 使用不同的数据库文件（文件内有命名空间标记，被调换会拒绝启动）、不同的账户绑定、风控版本、执行适配器与工作进程。
- 浏览器开关不能开启实盘。实盘执行通道只能在以下全部满足时由工作进程创建（见 `backend/app/broker/gate.py`）：
  部署配置 `LIVE_TRADING_ENABLED=true` → 用户确认的真实账户绑定且 24 小时内只读验证通过 → 市场交易权限已验证 → 现金字段可靠 →
  live 中用户确认的非测试风控参数 → 已核对的真实费用表 → 有效且签名正确的运行授权 → 保护方案已验证 → OpenD 可连接。
- 通过后签发**进程内**一次性许可令牌；moomoo 适配器在每次下单前再次校验令牌与部署开关。没有令牌无法构造 REAL 通道；伪造令牌无效。
- 每个 SDK 调用显式传入 `trd_env` 与非 0 的 `acc_id`。演示/纸上交易路径从不构造 moomoo 执行适配器（有测试覆盖）。
- 运行授权由后端在登录会话内创建并 HMAC 签名；直接修改数据库或伪造请求得不到有效授权。

## AI 的边界

- AI 进程没有任何交易工具、账户信息或密钥；只接收行情特征、持仓摘要与不可信新闻文本，只能返回结构化 JSON。
- 新闻、网页、文件都作为 `untrusted_news` 数据；系统提示明确其中的指令不是指令。即使模型被注入，输出仍要经过校验：
  证券必须在本次候选/持仓中、证据编号必须存在、目标仓位/持有期不超过政策上限、必须有止损、版本和数据时点必须一致、未过期。
- AI 不能扩大股票池、修改止损、提高额度、修改提示词或政策；这些都不在输出结构中（额外字段直接拒绝）。
- 保存模型名称、提示词版本、输入快照与输出，用于复盘；不要求也不保存隐藏思考过程。

## 威胁边界（首版）

| 威胁 | 措施 | 残余风险 |
| --- | --- | --- |
| 其他网页跨站请求 | CSRF + Origin + Host + SameSite | — |
| 本机其他用户读取文件 | 密钥文件 0600 | 管理员/同一用户账户下的恶意软件仍可读取 |
| 提示注入 | 不可信数据隔离 + 输出白名单校验 + 风控 | 模型可能在合法范围内做出糟糕决定（由风控限额约束损失） |
| 重复下单 | 意图唯一键、成交唯一键、单实例锁、不自动重发 | 券商 remark 不保证幂等，只作关联线索 |
| 断网/关机 | 停止新开仓；无法保证平仓 | 本地/客户端止损在关机时不会触发 |
| 误开实盘 | 部署开关 + 闸门 + 再次输入密码 | — |
