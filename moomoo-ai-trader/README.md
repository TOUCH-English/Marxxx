# Moomoo AI 自动交易工作台

您只需要设置 **可使用资金、可承受亏损、交易范围**，确认一次运行授权；之后由 AI 持续分析、在授权范围内自己选择标的、决定买卖，
程序自动风控、自动下单、自动止损/止盈/减仓，并每天生成中文日报。不需要逐笔确认。

- 先用同一套「决策 → 风控 → 下单」流程做**自动模拟**（无需账户、无需 AI 密钥即可运行）。
- **真实自动交易（LIVE_AUTO）功能已实现，交付时关闭**：需要您完成账户连接、核对费用、设置实盘风控并在部署配置中打开后才能启用。
- 本软件不是已验证能盈利的交易策略，也不构成投资建议。演示证券为虚构。所有数字只是您的设定，不代表收益预期。

---

## 一、启动（第一次约 5–10 分钟）

需要：**Python 3.11 或以上**（https://www.python.org/downloads/ ，Windows 安装时勾选 “Add python.exe to PATH”）。
前端已预先构建，**不需要** Node.js。

| 系统 | 启动 | 停止 |
| --- | --- | --- |
| Windows | 双击 `scripts\start.bat` | 双击 `scripts\stop.bat` |
| macOS | 在「访达」双击 `scripts/start.command`（首次若提示无法打开：右键 → 打开） | 双击 `scripts/stop.command` |
| Linux（或 macOS 终端） | `./scripts/start.sh` | `./scripts/stop.sh` |

启动脚本会：检查环境 → 创建 `.venv` 并安装锁定版本的依赖 → 生成 `.env`（默认：实盘关闭、无密钥时用固定测试响应）→
初始化数据库 → 启动网页和后台工作进程 → 打开浏览器 `http://127.0.0.1:8710/`。

首次打开网页：设置一个**本机网页密码**（只保护这个网页；不要在这里输入 moomoo 密码）。

## 二、看自动模拟（无需任何账户）

1. 打开「启动向导」→ 选择 **演示（DEMO）**。
2. 填写可使用资金（如 20000 MYR、5000 USD）和可承受亏损（如 1000 MYR、250 USD）。
3. 交易范围选「授权股票池」，查看程序筛出的成员和被排除的原因（杠杆 ETF、低流动性等）。
4. 阅读授权摘要（含小额交易的费用影响）→ 勾选确认 → 开始。
5. 回到「总览」：您会看到 AI 自动买入、持仓、自动减仓/卖出、止损，以及「今天做了什么」「为什么交易或没有交易」。
   演示数据按回放时钟加速（每 2 秒前进 30 分钟交易时间），几分钟内就能看到完整流程。
6. 「模拟与复盘」可运行回测、下载 CSV、查看中文日报；「复盘与改进」查看经验与候选改进。

没有 AI 密钥时，AI 决策由「**固定测试响应**」生成（确定性规则模拟 AI 的输出格式），页面会明确标示。
它只用来验证自动流程，**不代表任何 AI 投资表现**。

## 三、需要您做的最少操作（按需，一次说清楚）

**A. 接入 moomoo（只读诊断、纸上交易、以后实盘都需要）**
1. 在这台电脑安装并打开 moomoo OpenD（https://www.moomoo.com/download/OpenAPI ）。
2. 在 OpenD 窗口用 moomoo 账号登录 —— 密码和验证码**只在 OpenD 里输入**，不要发给任何人或填进本系统。
3. 确认 OpenD 监听 `127.0.0.1:11111`。
4. 到本系统「连接与权限诊断」点「重新检测」，然后**明确选择**要使用的账户（系统不会默认用第一个），再带账户检测一次。

**B. 使用真实 AI（可选）**：在项目根目录 `.env` 中填 `ANTHROPIC_API_KEY=...`，重新运行启动脚本。
模型 API 按量计费，与 Claude 聊天订阅无关；预算在 `.env` 中设置（默认每月 30 美元，用完即停止 AI 调用，止损等保护不受影响）。

**C. 启用真实自动交易（以后，确认模拟结果后再考虑）**——全部满足才会开放（「连接与权限诊断」页底部有核对清单）：
1. 完成 A，并对真实账户的只读诊断通过（市场交易权限、现金字段、订单类型探测）。
2. 「设置 → 费用」按 moomoo 官网当前收费填写并勾选「已核对」。
3. 在「真实自动交易」页面的「策略与风控设置」中单独设置并确认实盘风控参数和交易范围（不会沿用模拟参数）。
4. 保护方案：券商原生止损单只读探测通过；或您在 `.env` 设 `ALLOW_CLIENT_SIDE_STOPS_LIVE=true`，接受「电脑关机/断网时不会止损」。
5. 在 `.env` 设 `LIVE_TRADING_ENABLED=true`，重新运行启动脚本。
6. 在启动向导选择「真实自动交易」，用小额资金、填写可承受亏损和期限，再次输入网页密码确认一次。之后在授权期内自动运行。

## 四、暂停、紧急停止、清仓（三者不同）

| 按钮 | 作用 | 不会做的事 |
| --- | --- | --- |
| 暂停新开仓 | 不再买入新的风险 | 不卖出；止损、止盈、减仓照常 |
| 紧急停止新交易 | 停止新开仓并逐单撤销系统挂起的入场单 | 不卖出任何持仓；保护性订单默认保留 |
| 手动清仓 | 卖出**系统管理的**持仓（需勾选确认） | 不碰账户里的其他持仓 |
| 停止本次运行 | 撤销运行授权，立即停止新开仓 | 已有持仓继续按保护规则管理 |

关闭浏览器或退出登录**不会**停止已授权的后台运行；要停止请用上面的按钮或运行停止脚本（停止脚本会让止损也停止）。

## 五、备份与排障

- 备份：「日志与设置」→「立即备份」，文件在 `data/backups/`。恢复步骤见 `docs/runbook.md`。
- 网页打不开：看 `data/web.log`；端口被占用时在 `.env` 改 `APP_PORT`。
- 没有任何交易：看总览「为什么没有交易」——常见原因：休市、行情过期、名额已满、风控锁定、AI 选择不交易（这是正常结果）。
- OpenD 连不上：确认 OpenD 已登录、端口一致；诊断页会给出中文原因和步骤。
- 订单「状态未知」：系统不会重发；按 `docs/runbook.md` 核对。

## 七、开发者

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.lock.txt
.venv/bin/python -m pytest                      # 全部验收测试
.venv/bin/python scripts/demo_e2e.py            # 可复现的端到端示例 → data/examples/demo_run/
cd frontend && npm ci && npm run build          # 重新构建前端（需要 Node.js 20+）
cd backend && ../.venv/bin/python -m uvicorn app.api.app:app --port 8710   # 网页
cd backend && ../.venv/bin/python -m app.workers.main --ns sim             # 模拟工作进程
```
