# 景点照片（可选）

想给某个景点配图，就把图片放进这个文件夹，**文件名用下面对应的 key，扩展名 `.jpg`**。
推送上去之后，点开那个景点的讲解弹窗，照片就会出现在最上面。

没放的景点完全不受影响 —— 页面照常显示，不会有空白框，也不会变慢。

## 建议

- 尺寸 **1200×750 左右**（16:10），文件控制在 **200KB 以内**，手机流量打开才快
- 横图比竖图好看，因为卡片是横的
- 照片来源最省事的办法：点景点弹窗里的「小红书看攻略」，从里面存一张
